# Update documentation

Read the assigned documentation and the completed implementation or verification summary. Update only the pages that describe the changed behavior. Prefer examples a reader can actually run and remove statements made false by the change.

Check names, commands, paths, and defaults against the current code or confirmed results. Report edited files and any behavior that could not be verified. Send the result to the agent that assigned the task.
