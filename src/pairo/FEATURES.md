Subscription event pipeline: `EventPipeline` is a transient principal-loop broadcaster with `listen`, `subscribe`, `unsubscribe`, and `push`. Every `Subscription` owns one buffered queue and one delivery task, preserving FIFO delivery without overlapping its callback, and exposes `wait_until_cancelled()` as an asynchronous cancellation signal. Subscriptions are independent, callbacks may be synchronous or asynchronous, callback results are ignored, failures reach the loop exception handler, and matching includes subclass events. `listen` is implemented as a temporary subscription. The pipeline has no history, replay, central worker, receipt, or lifecycle API. Cross-thread work is isolated in `SynchronousEventPipeline`. [status: accepted]

Agent-scoped event observers: `AgentEventListeners` exposes typed event-named registration methods with optional agent filtering. Agent events match immutable agent IDs and network messages match recipient IDs. Each registration returns the underlying idempotently removable `Subscription`; duplicate registrations remain independent and all registrations are future-only. [status: accepted]

Async agent runtime: `CodexAgent` and `FakeAgent` implement the asynchronous `Agent` protocol, own their asyncio tasks, retain only one active session and turn, and publish transient notifications through the event pipeline. Repositories remain authoritative for durable session metadata and transcripts, and application operations explicitly persist successful session creation and activation. [status: accepted]
shared-conversation-event-log: `ConversationEventLog` observes every future `BaseModel` event from an `EventPipeline` and appends UTF-8 JSON Lines records independently of transcript persistence. It preserves subscription FIFO delivery, offers draining `flush`/idempotent `close` lifecycle methods, and is publicly exported. [status: accepted]
